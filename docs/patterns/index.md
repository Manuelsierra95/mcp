# Patrones

## Conceptos

- [El BRAIN es la fuente de verdad](el-brain-como-fuente-de-verdad.md) — Cómo se consulta, cómo se escribe y por qué el índice y el log se generan. Se aplica a cualquier trabajo que toque el BRAIN o que dependa de él.
- [El onboarding de un proyecto nuevo](el-onboarding-de-un-proyecto-nuevo.md) — Cómo un proyecto que empieza de cero consigue sus convenciones: cuatro preguntas en lenguaje llano, una elección sobre algo concreto, y cuatro convenciones escritas. Se aplica al empezar un proyecto, no al cambiar uno.
- [Feature Driven Development](feature-driven-development.md) — Cómo se trabaja en este proyecto cuando algo se pide por functionality: primero la feature, luego sus escenarios, luego el código. Se aplica a las features y a las rutas bajo features/.
- [Una regla comprobable o un patrón, nunca las dos](reglas-comprobables.md) — Cómo se decide si una convención se escribe como Rule o como prosa, y por qué esa frontera evita discusiones en cada revisión.
