# Lecciones

## Conceptos

- [El frontmatter YAML se rompe con dos puntos sin comillas](0001-el-frontmatter-yaml-se-rompe-con-dos-puntos.md) — Una description con dos puntos y sin comillas hace que YAML lo lea como un mapa anidado, y el concepto entero deja de parsear. El linter ahora lo dice con la solución.
- [Una regla que no dispara es peor que no tenerla](0002-una-regla-que-no-dispara-es-peor-que-no-tenerla.md) — La regla de imports profundos no se ejecutaba nunca, porque comparaba el import con igualdad exacta. Una puerta que no se cierra da una falsa sensación de seguridad.
