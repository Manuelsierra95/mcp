# Slice

Un trozo de una feature: un grupo de escenarios que se puede entregar por
separado y que **vale por sí solo**.

El criterio para partir una feature es el valor, no el orden ni el
esfuerzo. Un slice que no se puede usar por separado no es un slice: es
una parte.

En la feature, los slices son las secciones `### AC-n · <qué pasa>` dentro
de `## Slices`.
